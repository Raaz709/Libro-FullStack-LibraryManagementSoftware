# Library Management System

## Overview
A full-stack Library Management System designed to manage books, members, borrowing, returning, and other library operations.

## Tech Stack

### Backend
- ASP.NET Core Web API
- C#
- .NET 10
- Dapper

### Frontend
- React
- TypeScript
- Vite

### Database
- MySQL

### Tools
- Swagger
- Git
- GitHub
